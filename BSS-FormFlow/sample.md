のStateにより、ページリロードなしで一覧画面と複製作成フォームを同一コンポーネントツリー内で切り替えます。 2. **複製データの引継ぎロジック（`handleStartDuplicate`）**: - 元のレコード情報（企業名、適用プラン、金額、請求サイクルなど）を丸ごとコピーしつつ、**「契約IDの自動再採番」**や**「プラン名への (複製コピー) 付与」**、**「ステータスを安全に "下書き" にセット」**した初期値を生成してフォームに流し込んでいます。 3. **完全なレイアウトプリミティブ構成**: - CSSスタイルシートやTailwindの長いクラス名に依存せず、`<Box>`, `<Flex>`, `<VStack>`, `<HStack>`, `<Table>` とそのProps（`p={6}`, `bg="#eff4ff"`, `mr="450px"` など）だけで画面全体の配置とドロワーのアニメーション余白を実現しています。 React Router等の外部ルーティングを使いたい場合は、`setViewMode('duplicate_form')` の部分を `navigate('/contracts/new', { state: { initialData: duplicatedPayload } })` に差し替えるだけでそのまま実務システムに組み込めます。 さらに特定の項目（バリデーションや別ライブラリ向け記法など）の追加が必要でしたら、いつでもお申し付けください！
